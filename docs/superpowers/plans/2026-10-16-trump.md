# Broforce: Donald Trump and his jet — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A third bro, Donald Trump. He has Broniversal Soldier's burst-fire rifle, and a signal grenade that brings
down a stealth-grey Harrier. He boards it, flies it with rockets and bombs on 20 s of fuel, and his own meme sound
plays while he flies (the US anthem as fallback).

**Architecture:**
- **Extractor:** adds a recipe for Trump's sheet, the rifle's gun texture, the Harrier with a *tone* recipe (its art
  is painted, not palettized), the soldier's and bullet's values, and the US anthem.
- **Shared vehicle layer:** the tank's piloting layer becomes a generic `Vehicle` (`engine/vehicle.ts`, with the
  world glue in `driving.ts`): boarding, stand-clear re-boarding, the hidden and shielded driver, exits, enemy hits,
  the countdown and the gib. `Tank` keeps its body and turret.
- **Jet:** a new `Jet` (`engine/jet.ts`) adds descent, flight, fuel and leaving, and its controls fire `bomb`
  rockets and drop `jetBomb`s.
- **Rifle:** a weapon kit with its own step (burst fire).
- **Music:** `Music` gains a source list with fallback.

**Tech Stack:** Python 3.12, UnityPy, Pillow, pytest · TypeScript 5.7 (`strict`, `noUnusedLocals`), React 18.3, Vite 6, Vitest 2.1.

**Spec:** `docs/superpowers/specs/2026-10-16-trump-design.md`

```python
def stealth(rgb: RGB) -> RGB:
    """The Harrier is painted (1196 colours), so it is toned rather than mapped: greys go dark slate, and the bluish
    cockpit glass is kept."""
    r, g, b = rgb
    if b > r + 40 and b > 150:
        return rgb
    v = round((0.3 * r + 0.59 * g + 0.11 * b) * 0.42 + 10)
    return (v, v, min(255, v + 6))
```

```ts
      const top = r * TILE + HALF_TILE;
      if (map.get(c, r) && top <= y + EPS) {
        best = Math.max(best, top);
        break;
      }
    }
  }
  return best;
}

const approach = (v: number, target: number, step: number): number =>
  v < target ? Math.min(target, v + step) : Math.max(target, v - step);

/** One fixed step of the jet: its descent, its flight while piloted, or its leaving. */
export function stepJetBody(j: Jet, drive: JetDrive, map: TileMap, t: number, screenMaxY: number): void {
  j.animTime += t;
  if (j.state === 'leaving') {
    j.yI = JET_LEAVE_SPEED;
    j.y += j.yI * t;
    j.onGround = false;
    if (j.y > screenMaxY + 64) j.exploded = true;
    return;
  }
  if (j.state === 'flying' && !j.driven) j.state = 'descending';
  if (j.state === 'descending') {
    const ground = groundBelow(map, j.x, j.y);
    const speed = j.y - ground > JET_DESCENT.slowZone ? JET_FAST_DESCENT : JET_DESCENT.slow;
    j.xI = 0;
    j.yI = -speed;
    j.y -= speed * t;
    j.onGround = false;
    if (j.y <= ground) {
      j.y = ground;
      j.yI = 0;
      j.onGround = true;
      j.state = 'landed';
    }
    return;
  }
  if (j.state === 'landed') {
    j.xI = 0;
    j.yI = 0;
    j.onGround = true;
    return;
  }
  // flying, piloted
  if (drive.dx !== 0) j.facing = drive.dx;
  j.xI = approach(j.xI, drive.dx * JET_FLY.x, JET_FLY.accel * t);
  j.yI = approach(j.yI, drive.dy * JET_FLY.y, JET_FLY.accel * t);
  const nx = j.x + j.xI * t;
  if (boxHits(map, nx, j.y)) {
    if (j.xI > 0) j.x = cellLeft(getColumn(nx + JET_BOX.halfWidth)) - JET_BOX.halfWidth - EPS;
    else if (j.xI < 0) j.x = cellLeft(getColumn(nx - JET_BOX.halfWidth)) + TILE + JET_BOX.halfWidth + EPS;
    j.xI = 0;
  } else {
    j.x = nx;
  }
  let ny = j.y + j.yI * t;
  const top = map.rows * TILE - HALF_TILE - JET_BOX.height; // no higher than the map's top row
  if (ny > top) {
    ny = top;
    j.yI = Math.min(j.yI, 0);
  }
  if (boxHits(map, j.x, ny)) {
    if (j.yI <= 0) j.y = cellBottom(getRow(ny)) + TILE;
    else j.y = cellBottom(getRow(ny + JET_BOX.height)) - JET_BOX.height - EPS;
    j.yI = 0;
  } else {
    j.y = ny;
  }
  j.onGround = boxHits(map, j.x, j.y - 0.5);
  if (!j.onGround) j.fuel = Math.max(0, j.fuel - t);
}
```
